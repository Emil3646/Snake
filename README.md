# Snake Spiel

Snake ist auf Desktop und Mobilgeraeten spielbar.

## Steuerung

- Desktop: `WASD` oder Pfeiltasten zum Bewegen, `SPACE` fuer Start/Pause/Fortsetzen.
- Mobil: `START`-Button zum Starten/Neustarten, On-Screen-Pfeiltasten zum Bewegen und `PAUSE` zum Pausieren/Fortsetzen.

## Responsives Verhalten

- Auf Desktop bleibt das bestehende Layout unveraendert.
- Auf Mobilgeraeten werden die Touch-Controls unterhalb des Spielfelds angezeigt.
- Auf Mobilgeraeten werden Start und Pause ausschliesslich ueber Buttons bedient.
- UI-Leiste (oben), Spielfeld (Mitte) und Touch-Buttons (unten) sind getrennte Bereiche.
- Das Spielfeld skaliert automatisch bei Groessen- und Orientierungswechsel.
